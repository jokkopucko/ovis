### Added
- An optional Close tab button beside Attach files in the chat's message box. Name a skill in
  Settings → Chat → Composer → Close tab button (for example `close-tab`), and the button asks,
  after a yes, the agent to run that skill, so the agent checks for open work and questions before
  it closes its own tab. It shows only on the devices that name the skill, and only in panes whose
  agent lists it (Claude Code, Codex and the other agents with skills).
